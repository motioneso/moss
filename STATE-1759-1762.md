Workflow: Ben browses the dev site and drops live annotations via Agentation. Watch with
mcp**agentation**agentation_watch_annotations in a loop, or check
mcp**agentation**agentation_get_all_pending for everything outstanding right now (it only ever
returns items that are still unresolved/unacknowledged, so nothing stale shows up there).

For each annotation:

- Mechanical fix (copy, layout, a small bug) -> fix directly, commit with real file paths (never
  git add -A, never a bare git commit -- this is a shared checkout, use the shared-checkout skill
  if unsure how), reply to the annotation explaining the fix, then resolve it.

  annotation with the issue link, then acknowledge it (not resolve) so it stays open and Ben
  knows not to re-annotate it.

## Quirk to watch for

Every page reload re-submits all still-visible annotations under brand-new session/annotation
ids, sometimes with the exact same timestamp as the original. Cross-check comment text +
timestamp against anything you've already handled before redoing work.

af1672859 and ded7ba3ba):
