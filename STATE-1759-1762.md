# Live UI fixes state (Agentation loop) -- branch ui-live-fixes

Workflow: Ben browses the dev instance (http://192.168.50.36:5173) and drops live
annotations via Agentation. Watch with mcp__agentation__agentation_watch_annotations
in a loop. For each annotation:
- Mechanical/copy/layout/bug fix -> fix directly, commit (explicit paths only,
  never git add -A -- this is a shared checkout, see the shared-checkout skill),
  reply explaining what changed, then resolve.
- Needs a product decision -> file a GitHub issue (repo motioneso/moss), reply
  linking the issue number, then ACKNOWLEDGE (not resolve) so it stays pending
  and Ben knows not to re-annotate it.

No PR opened yet for this branch. When one is opened: fill in the Release Note
section and run `node scripts/append-release-note.mjs --pr <number>`, commit
the resulting docs/WHATS_NEW.md change onto the same branch (CLAUDE.md rule).

## Watch loop quirk (confirmed again this session)

Every page reload re-submits all still-visible annotations under brand-new
session/annotation ids, sometimes with the exact same timestamp as the
original. Always cross-check comment text + timestamp against already-handled
annotations before redoing work -- dismiss the duplicate id with a note
pointing at the original id, don't refix.

  email, chat, news, sports, food, workshop) showed the wrong icon or the

  correct by reading the code (the title was threaded through properly);
  only reproduced live. Real cause: a second effect in
  task-details-dialog.tsx re-built the form right after it opened and
  dropped the typed title on the floor. Fixed by passing the title into
  that effect too. Verified live that the text now survives. Commit
  7ed68ff63.
- **mt7jzztq** -- Tasks page toolbar right side (filter, then list/matrix
  toggle) left large empty gaps at medium widths. Cause: the layout used a
  single stretchy spacer to push the toggle to the right edge, which only

  spacer's stretch applied to whichever line it landed on instead. Split
  the bar into two independent left/right groups that each wrap on their
  own. Checked visually at several widths from 1280px down to 480px
  (mobile), including the two-row mobile layout below 560px. Commit
  489ce9b7f.
