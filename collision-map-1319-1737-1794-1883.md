### #1794 - release notes through protected main
- Tier: **sensitive**. Escalate to security if the implementation needs a new repository secret or
  asks for workflow permissions beyond opening a pull request.
- State: there is currently no release-notes workflow at all. The merge-time job was removed in
  #1795 because it pushed straight to main. Today a human or agent runs
  `scripts/append-release-note.mjs` by hand on the branch.
- Touches `scripts/append-release-note.mjs`, a new file in `.github/workflows/`, the release-notes
  page format, and almost certainly the release-note paragraph in `CLAUDE.md` and the development
  standards doc.
- **Two sequencing traps, both real:**
  1. It changes the shape of the release-notes page while every other lane in the run is appending
     to that same page. If it lands first, the other branches were cut against the old shape and
     will conflict. **Merge it last.**
  2. Its own proof requires a real merged pull request to fire the new automation, which means
     something has to merge *after* it. Reserve a small closing pull request for that - the run's
     own wrap-up docs commit works - and do not treat the lane as done until that proof exists.
  3. Because it changes the process instruction agents follow, landing it mid-run changes the
     rules under lanes already in flight. Same conclusion: last.

### #1883 - surface vault search failures
- Tier: **security**, and not marginally so.
- The generic error it complains about is deliberate. In `packages/chat/src/mcp-transport.ts` the
  tool-call handler catches the failure and returns a flat internal error, with a comment saying
  it must never echo the message because it may carry database detail. This lane is asking to
  relax an existing fail-closed scrub at a boundary a model talks to.
- So the adversarial review must ask the opposite question from usual: not "is the cause visible
  enough" but "can the new classification become a leak channel for vault content, query text,
  credentials, or database values". A fixed vocabulary of causes is safe; anything derived from an
  exception message is not.
- Vault search is `notes.search` (`packages/notes/src/manifest.ts`). Files: the MCP transport, the
  gateway tool path, plus new tests alongside `tests/unit/mcp-gateway-recovery.test.ts` and
  `tests/integration/mcp-gateway.test.ts`.
- Small, self-contained, touches nothing any other lane touches, and it is the diagnostic tool for
  a live outage. Good first merge.
