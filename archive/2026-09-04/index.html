Moss weekly Issue #36

Week of August 31, 2026

This was a big one. The headline is a genuinely new capability: Moss can now plug into outside tools and services directly from Settings. Alongside that, Gemini joins the list of chat models, Sports and Settings both got real attention, and a long list of small but noticeable fixes went out. If you only read one section, the fixes at the bottom are worth a skim.

This week's headline

Connect Moss to outside tools and services

You can now connect Moss to external services that speak MCP or publish an OpenAPI specification, right from Settings, and put their capabilities to work in chat. This opens Moss up to a much wider range of tools beyond what ships built in.

The connection screen also got a pass of its own: tools are grouped for easier scanning, each one has its own switch so a call that's meant to repeat isn't mistaken for a duplicate, and if you already had a large connection turned on before grouping existed, Moss tells you so.

PR #2171·PR #2190

New

Chat with Google's Gemini

Gemini is now a real option for chat, not just a name in a list. Sign in to Google and pick it alongside Claude and Codex.

PR #2048

Tell Sports what you want more or less of

Sports stories now come with preference controls, and you can review and manage those choices in Sports Settings.

PR #2052

Choose which leagues show up in standings

Pick which leagues appear in standings and jump straight to the ones connected to teams you follow, including college football, college basketball, WNBA and NWSL, with Select all and Clear all to speed it up.

PR #2069·PR #2071·PR #2210

Ask Moss about its own health

Moss can now explain its current service health when you ask, and can kick off a news refresh on request.

PR #2056

Approve workflow steps in chat

You can approve or reject a workflow step directly in chat, and once approved the workflow continues safely.

PR #2065

Add an email account by typing its address

Connecting an email account now starts with your address instead of picking a provider tile. For Yahoo, Proton, iCloud and Fastmail, Moss fills in the setup instructions and server details for you.

PR #2215

Newly built module abilities show up right away

When Moss finishes building a module that adds a new chat ability, that ability is available immediately, no restart needed.

PR #2101

Improved

Fresher AI provider models, and no more duplicate sign-ins

Your list of Claude and ChatGPT models is now pulled from the vendor when you sign in and with a new Refresh models button, so new models show up without waiting for an update. You can also add a model by hand or remove one, and the list can collapse. Signing in to a provider you already had no longer creates a duplicate, and removing your default provider properly hands the default to the next one.

PR #2206

Search box in Settings, and a searchable time zone picker

Settings now has a search box up top so you can jump straight to what you need, and the time zone picker lets you type to find yours instead of scrolling. Weather settings are tidier, with Fahrenheit as the default, and the Appearance page got a cleaner layout.

PR #2212

Quieter chat while Moss works, tidier feedback

While Moss is working you now see its status updates right in the chat, with a small collapsible "Thinking..." line instead of a busier display. The feedback menu on a reply now tucks into the corner until you hover over it.

PR #2214

Sports desk cleanup

News sources now show the publication's icon and a coloured health badge, you can open a source to see the articles it links to, and the add-a-source and standings picker forms stay tucked away until you open them. Settings is organized into Following, News sources and Configure standings sections.

PR #2210·PR #2057

The Chat tag is now the on/off switch

On each AI model row, the Chat tag itself now turns chat access for that model on or off, replacing the separate switch that used to sit next to it.

PR #2216

Activity history shows how long things took

Your activity history now shows how long each assistant action took, and can tell you when a repeated request was automatically skipped instead of run again.

PR #2191

Fixed

  • Adding a medication shows up immediately, and email sync keeps your contact details even when optional extraction isn't available. #2059
  • Building a module in the Workshop no longer occasionally submits the build step twice. #2060
  • The GitHub tile no longer appears when adding a connected account, since GitHub support isn't planned. #2070
  • The story feedback control no longer appears where it didn't belong, on the Followed-teams strip. #2076
  • The standings dropdown now updates right away when you follow or unfollow a team. #2094
  • Visiting a self-hosted Moss server by its numeric network address in Firefox now loads securely instead of sometimes failing. #2105
  • The small label next to an assistant action now correctly says Executed, Allowed, Failed, or Denied. #2116
  • Saving or changing notes and memory is more reliable and no longer reports a false failure. #2144
  • When a note change is blocked for a known, safe reason, Moss now explains why instead of showing a generic failure. #2148
  • Meals logged with a local time now save on the correct calendar day. #2155
  • Approving a change now waits for it to actually finish before showing the updated status. #2158
  • The assistant no longer announces the date and time unprompted at the start of nearly every reply. #2186
  • Asking the assistant for the time now gets an answer in your own time zone instead of UTC. #2192
