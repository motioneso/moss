Moss weekly Issue #37

Week of September 7, 2026

A lively week with a major step forward for how Moss builds things. The headline is Workshop projects: you can now start named projects, talk through what you want built, and return to an ongoing workspace with your chat history preserved. Web search is now on by default in chat, push notifications arrived in Settings, and headings across the app got a typographic facelift alongside a long list of fixes.

This week's headline

Workshop projects: ongoing workspaces for what you build

Building a custom module in Moss is no longer a one-shot prompt. You can now start named Workshop projects, talk through what you want with Moss in an ongoing chat workspace, and return anytime to pick up where you left off.

The Workshop home page now organizes your work in a tidy list, project conversations render formatted responses instead of raw markup, and you can easily rename or remove projects as they take shape.

New

Web search on by default for chat

Chat now searches the web automatically using your AI model's built-in search or Brave Search, bringing up-to-date facts and cited sources into everyday conversations.

PR #2280

Browser push notifications

You can now turn on browser push notifications from Settings → Notifications, so Moss can notify you when actions complete even when the tab isn't open.

PR #2234

Manage encryption keys right in Settings

Administrators and owners can generate and rotate encryption keys across all three key families directly from Settings, with an initial setup banner that replaces manually edited files.

PR #2315·PR #2323

Photos for custom sports sources

Stories from sports feeds and sites you add yourself now show photos, and Sports Settings lets you see photo status or turn off automatic photo discovery for any source.

PR #2245·PR #2273

Use browser location for weather

A new 'Use my location' button in Account & preferences sets your weather location from your browser with a single click.

PR #2217

Improved

New display typeface and lighter page palette

Headings across the app now use a refreshed display typeface, and pages sit on a lighter, softer background for easier reading.

PR #2333

Seamless web page reading

When you ask the assistant to read a web page, it now opens and reads it directly without asking you to approve every individual link.

PR #2331

Smarter email task filtering

Moss now evaluates whether an email actually asks something of you before suggesting tasks, and sign-in or verification codes are never turned into to-dos.

PR #2279·PR #2257

Settings search covers modules

Searching in Settings now finds module-specific configuration pages—like News or Sports—and jumps straight there.

PR #2254

Organized News settings and subreddit sources

News settings are organized into topics, sources, and story preferences, with AP News added as a default publication and support for subreddit feeds.

PR #2221·PR #2298

Soccer and hockey scoring cards

Finished soccer and hockey score cards now display both team logos side by side with the score and list each goal scorer.

PR #2253

Response style in Assistant & AI

Setting your preferred answer style—concise, balanced, or detailed—now lives in Assistant & AI alongside persona settings.
