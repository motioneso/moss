Moss weekly Issue #42

Week of October 19, 2026

This was the week Moss started listening. Recordings from a Vocci ring can now land in Meetings with a transcript and a summary, your Outlook calendar can show up next to everything else, and chat learned to work with an API key. Reminders also got two fixes, so the one you ask for first actually sticks.

This week's headline

Your ring recordings now reach Moss

Record a conversation on a Vocci ring and it can now find its way into Meetings, complete with a transcript, a summary, any bookmarks you tapped, and tasks and follow-ups you can review before keeping. An Android companion app carries the recordings over, picks up where it left off if an upload gets interrupted, and handles meetings up to about two hours long.

If you opt in, a recording made while holding the ring's button is treated as a question for me instead. It shows up in your Main chat for you to check and send, and I answer in text. This is still an early preview: the Android app is installed by hand and pairing the ring takes some developer setup, so it isn't ready for everyone yet.

New

Outlook calendar, read-only

Connect a dedicated Outlook browser and your upcoming meetings, from yesterday through the next 30 days, appear in Calendar and refresh every five minutes. Moss looks but never touches, and it warns you when the connection needs a fresh sign-in or can't be sure it saw everything. It needs to be set up by whoever runs your Moss before you can switch it on.

PR #3568

Chat with your own API key

Admins can now point chat at an Anthropic or OpenAI-compatible provider using an API key, including one at its own web address. Tools and confirmation cards work just as they do with a sign-in provider, and a pasted address with an extra slash or a trailing /v1 just works.

PR #3540

Changed

Job Search is archived

Job Search is no longer offered as a module download. If you already have it installed, it stays put along with its data.

PR #3561

Fixed

  • Week and Month in Calendar open on today, and Month fits the screen without sideways scrolling, even on a phone. #3573
  • Tapping a reminder's alert or its notification opens that reminder in its chat, not the Today page. #3542
  • A reminder asked for in a brand-new account's very first chat message is saved, and it appears when it fires without reloading chat. #3544
