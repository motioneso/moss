# Meetings package

## 0.1.1

- The Meetings screen is part of the package. It lists meetings with search and a type filter, adds a pasted transcript, and opens each meeting with its transcript, notes and summary.
- On a meeting you can rename it, change its type, edit notes, rewrite or edit the summary, compare versions, add suggested tasks to Tasks, save the summary to your private vault, copy it as Markdown and delete the meeting.
- The AI-settings hint tells admins where to change it and members to ask an admin. History hides when there are no meetings and no Mac is linked.
- Recording, the recording panel and the Meetings settings are not part of this package yet.

## 0.1.0

- Meetings starts as a built-in package. It keeps the same tables and saved data as before.
- Meeting records, personal notes with version checks, and recording defaults work through the same routes as before. They stay private to each account.
- Recording, transcripts, summaries, search, exports and the Meetings screen are not part of this package yet.
