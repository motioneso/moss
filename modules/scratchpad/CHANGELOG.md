# Scratchpad package

## 0.1.0

- Scratchpad starts as a built-in package that cannot be turned off. It keeps the same table and saved note as before.
- Reading the note, saving over it, adding a line to the end and changing its two settings work through the same routes as before. The note stays private to each account.
- The Scratchpad screen and the assistant tools are not part of this package yet.
