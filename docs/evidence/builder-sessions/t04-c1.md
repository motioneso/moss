| Old approval card or pending action | Resolution requires a pending row owned by the actor and a live waiter; timed-out rows return "expired" and cannot grant a later run. No test found that restarts with a pending card; `gateway-action-request-lifecycle.test.ts` is the nearest entry point. |
| Revoked consent or module permission turned back on | Dispatch re-resolves consent and module at execution, so a card approved under the old state is refused if state changed, and re-enabling does not revive a spent or expired approval. An approval cannot enable AI consent. | Source-read; not run. |
| Old launch-replay or seed content | Replay is refused for Moss tools; post-launch seed is admitted and marked but its dedupe key is in memory only, so a restored session can resubmit (#3339). | Known gap, unchanged. |
| Old voice request after restart | A request left dispatching under another boot id is marked interrupted, not resent. | Source-read. |
