## Case applicability by journey

Owning journey means the journey whose report must carry the case result. "Applicable" means the case must be run and recorded passed, failed or not run on that journey. "Pending" means applicability depends on an open decision or missing evidence, so it is neither run nor dropped. "Excluded" means another journey owns it. A case that cannot run stays "not run"; zero observed failures in an unrun case is not a pass.

Also whether non-YOLO trusted add-on writes to declared hosts after hostile content are acceptable. S12 cannot be finalized until Ben answers.

## Counting rules carried forward

- Every case is recorded passed, failed or not run against the exact build. A case that is not run says so.
- Applicability above is fixed before execution. Applicability does not change after a failure. A failed case stays in the denominator.
- Reminder coverage is S1-S10, S12 and S14 as applicable. S11 belongs to the briefing report. S13 belongs to the recovery and installer slice.
- A shared safety failure invokes the universal stop rule: unauthorized action, cross-owner exposure, consent failure, lost record, duplicate consequential effect, or false completion.
- No report states a target as supported. Today fallback is not Main landing.
