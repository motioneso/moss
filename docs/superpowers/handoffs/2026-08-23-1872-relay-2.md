## Live-path proof — DONE, evidence on disk, not yet on the PR

The LAN proxy setup from relay 1 needed one real fix: **the LAN IP address
(`http://192.168.50.36:4181`) does not work for this proof** — it's plain HTTP on a non-localhost
address, which Chrome refuses to treat as a secure context, so `navigator.serviceWorker` is
`undefined` there and registration silently fails. Use `http://127.0.0.1:4181` instead — same
running instance, Chrome treats localhost/127.0.0.1 as secure regardless of protocol. Also needed:
the proxy must rewrite the `Origin`/`Referer` headers on `/api/*` and `/health` requests to
`http://127.0.0.1:3000`, because Better Auth's default trusted origins are only
`http://localhost:3000` / `http://127.0.0.1:3000` and a bare pass-through proxy sends the wrong
origin, which the API rejects with "Invalid origin". Both fixes are already applied to the running
proxy at `/tmp/1872-live-proxy.mjs` (source still on disk, already restarted with the fix) —
nothing to redo unless the proxy or preview process died (restart commands are in relay 1's doc,
same idea, just remember the two fixes above if you rebuild the proxy from scratch).
