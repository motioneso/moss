# Issue #3164 evidence: quiet-hours writers refuse bad and stale saves

PR #3315, branch `scheduled/3164-quiet-hours-undo`, base `integration/scheduled-proactive`.

## Scope

- Three existing writers only: Profile quiet hours, the Moss chat quiet-hours tool with undo, and
  the alert settings save.
- No migration, no new editor, no redesign.

## Change

| Writer | Before | After |
| --- | --- | --- |
| Profile save | Plain overwrite, no checks on time zone or equal times | Validates new values; needs the version it loaded; stale save gets 409 and changes nothing |
| Chat tool | Server-read write, undo keyed on revision | Same validation; leaving out the time zone keeps it, null clears it; unchanged values write nothing |
| Chat undo | Revision check | Refuses when any other writer saved on top; never deletes a schedule recreated after it |
| Alert settings save | Read, merge, plain overwrite, no time checks | Locked read and revision-checked write, three retries, then 409; validates only newly supplied times; keeps old stored values that were not changed |

The app map gains a quiet-hours feature with three errors (invalid schedule, stale save, undo
cancelled) and their fixes, worded as the screens show them.
