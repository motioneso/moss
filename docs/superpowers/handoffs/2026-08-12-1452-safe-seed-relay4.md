## Extra findings for relay5 (not in the plan's prose — use directly, don't re-derive)

- **`.jds-brief` is NOT a unique class.** `apps/web/src/today/today-page.tsx` reuses it across ≥4
  sections ("Start here", "Walking the day", "Loose ends", "Morning briefing"). A bare
  `page.locator(".jds-brief")` is Playwright-strict-mode-ambiguous. **Scope by kicker text**, e.g.:
  ```ts
  const briefingCard = page.locator(".jds-brief").filter({ has: page.getByText("Morning briefing") });
  ```
  or locate via the kicker span (`.jds-brief__kicker`, text "Morning briefing") and walk to its
  ancestor `.jds-brief` container.
- **A fresh "bare"-level sign-up hits the onboarding wizard**, not the Today page directly — it
  becomes a founder/bootstrap-owner with pending onboarding. Insert a skip step between sign-up and
  the Task 1 step-2 empty-state assertion, mirroring the established pattern (seen verbatim in both
  `tests/uat/specs/real-chat-onboarding.uat.spec.ts` and `tests/uat/specs/1311-install-grant.uat.spec.ts`):
  ```ts
  const skipSetup = page.getByRole("button", { name: "Skip setup" });
  const userMenu = page.locator(".jds-usermenu__trigger");
  await expect(skipSetup.or(userMenu).first()).toBeVisible();
  if (await skipSetup.isVisible()) {
    await skipSetup.click();
    await page.getByRole("button", { name: "Skip anyway" }).click();
  }
  await expect(userMenu).toBeVisible();
  ```
  Note: those two exemplars use `solo-admin` + a pre-seeded admin sign-**in**; Task 1 is a real
  sign-**up** (bare level, `needsBootstrap` true) — the skip-wizard block still applies verbatim
  after sign-up submission, only the preceding sign-in/sign-up form-fill differs (use
  `auth-screen.tsx`'s Name/Email/Password fields + "Create account" button per plan seam #3).
- **Cookie-authed fetch pattern to copy verbatim** (plan seam #13, exemplar
  `tests/uat/specs/1311-install-grant.uat.spec.ts:76-79`):
  ```ts
  const body = await page.evaluate(async () => {
    const response = await fetch("/api/...", { method: "POST", headers: {...}, body: JSON.stringify({...}) });
    return { status: response.status, json: await response.json() };
  });
  ```
- **`tests/uat/playwright.config.ts` default test timeout was not resolved this session** — a
  `grep -n "timeout"` returned nothing. Before relying on the default, either grep again quickly
