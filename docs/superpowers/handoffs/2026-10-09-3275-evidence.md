# #3275 Mid-chat tool refresh and repeated calls evidence

The 2942 and 2950 live specs now start every fresh chat through Conversations and "New side chat" instead of the removed "New chat" button. No assertion was deleted or weakened and no label was renamed. Both specs ran live against the real configured model and a real MCP tool server, with captures switched off. A drawer bug found on the way is fixed, so a reopened side chat no longer shows the previous conversation's live turn. Each protection fails with its guard removed.

## Scope

- 2942 live spec: no tool before refresh, approved real effect in a new side chat.
- 2950 live spec: one switch per tool row at desktop and phone width, two identical calls inside one fresh chat both reach the tool server, grouped list after Refresh.
- Capture guards on every 2950 screenshot (2942 takes none).
- Protection unit test for both specs.
- Drawer live-turn fix and its unit test.
- Migration collision check: counts claimants by file path.
- Not touched: 3274 and 3276-3281 specs, #3210, #3273.

## Review

Two independent Claude reviewers read the diff with no session background. Neither found a must-fix.

- Spec helper checks the clear request, not that old replies left the screen: the helper does wait for zero reply bubbles, and the bounded settle covers the rest. Kept.
- Helper copied into both specs instead of the shared one: kept local so the specs stay self-contained; follow-up.
- Protection test counts button names and only recognises an unbraced guard: it can fail on correct code, never pass on a missing guard. Accepted.
- Drawer: live records with different wording from the stored copy can still show twice after a turn, and late events from a cancelled turn can land under a thread picked mid-turn. Both predate this change in other forms; follow-up.

## Migration number check

`495f9061a` fixes a false collision. A branch stacked on an open PR carries that PR's migration at the same path, which the check counted as two claimants. It now groups by path. Unit test added.
