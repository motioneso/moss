# Issue #3130 evidence: one quiet-hours editor on Alerts & quiet hours

Branch `scheduled/3130-canonical-quiet-hours-control`, base `integration/scheduled-proactive`.

## Scope

- One quiet-hours editor on Settings > Alerts & quiet hours, matching the accepted mockup (#3103).
- Profile and Notifications link to it. Profile keeps a read-only Quiet hours line.
- Saved, draft and error states stay apart. A failed save keeps the stored schedule and the draft.
- Conflicts and unreadable records are named. Nothing picks a winner or calls a merged value saved.
- No server change. The API, versioning and authority come from #3164 and #3165.
- Out of scope: the conflict choice (#3131), task exceptions and allowances.

## Change

| Area | Before | After |
| --- | --- | --- |
| Alerts & quiet hours | Email alert choice only | Two columns: alert choice, ruled divider, quiet-hours editor |
| Editor | None | Switch, From, Until, Time zone; draft with Unsaved changes; Save quiet hours; Try again on failure |
| Save | None | Sends the draft against the version it was built from; 409 shows the latest schedule |
| Offline save | None | Fails at once, keeps the draft and the stored schedule |
| Profile | Quiet hours controls | Read-only line for every state, Edit quiet hours link, Try again on a failed load |
| Profile time zone save | Locale only | Also reloads quiet hours, since the zone can open or close a conflict |
| Notifications | Own quiet-hours note | Note links to Alerts & quiet hours |
| Shared divider | Strong weight did not colour vertical rules | Vertical strong rule uses the strong border token |
| App map | Old Profile controls | Profile and Alerts entries describe every state, error and recovery |

## Reviews

Two fresh Opus 5.5 reviewers in sequence, because Codex is out until 2026-10-14.

- Standards and security: one must-fix (the save used the version current at Save, not the one the
  draft began from) and two should-fix (unreadable state missing on screen and in the map; no Try
  again on Profile). All fixed with tests.
- Acceptance: one must-fix (the Profile map entry missed the row's loading, empty, error and
  unreadable states) and four should-fix (Profile stale after a zone change; demo window not
  overnight; no worker downtime; leaving drops a draft silently). All fixed. Leaving the section
  still drops an unsaved draft, as in the mockup, and the map now says so.
