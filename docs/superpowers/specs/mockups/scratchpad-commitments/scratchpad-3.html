Scratchpad 3: the scratchpad beside chat

New screen, no TypeScript version exists. Follows the 2026-09-04 scratchpad design: a pencil button in the top bar opens a small pad on every page, Ctrl or Cmd + Shift + S toggles it, it saves as you type, and Moss can only add lines after you approve. Two changes from that design: the pad moves beside the chat drawer when both are open, and settings open from a cog in the pad header instead of a three-dot menu.
