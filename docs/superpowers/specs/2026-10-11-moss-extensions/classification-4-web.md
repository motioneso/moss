## Surprises

- `apps/web/src/today/today-page.tsx` holds the Today card order and the "Start here" ranking inline in a large page component. Both need lifting out into a server-side choice before anyone can extend them.
- `apps/web/src/today/today-labels.ts` and `apps/web/src/tasks/focus.ts` each define "at risk" separately, so the rule lives twice in the browser. Moving it to the server should merge them.
- `apps/web/src/chat/page-context.ts` mixes a secret-stripping rule (locked) with the choice of what page content Moss sees (open). Split it before the open half can move.
- `apps/web/src/settings/settings-personal-panes.tsx` and `settings-profile-subviews.tsx` mix plain profile preferences with data download and active sign-in sessions.
- `apps/web/src/settings/settings-integrations-pane.tsx` mixes checkpoint controls with key entry.
- `apps/web/src/api/client.ts` is one large pass-through client that also carries sign-in, session and password calls. Marked plain because the wall sits on the server.
- `apps/web/src/settings/settings-vault-chooser.tsx` and `settings-ai-sorting-row.tsx` were unclear and are locked to be safe.
