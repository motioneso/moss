Let the classifier use this connection

Quick requests such as "turn off the kitchen lights" can then skip your default model. You choose which tools, and you check each one first.

Before you prepare
Setup, one time. To draft descriptions, your default model reads this connection's tool definitions once. This costs one request to your default model's provider. Nothing is stored until you approve it. Credentials are never sent.

Later, on every request. When the classifier is on, each eligible chat message, the approved descriptions and the names of your devices are sent to the classifier's provider. This is separate from the one-time setup and is described on the Classifier setting.
