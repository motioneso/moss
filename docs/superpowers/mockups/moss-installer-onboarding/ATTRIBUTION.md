# Asset attribution

All assets are bundled locally. The review UI never downloads an icon or font.
Provider marks identify the corresponding option only and remain subordinate to
Moss. They do not imply sponsorship, endorsement, account connection or shipped
provider support. Bundled source artwork is unchanged.

## Original review assets

`assets/mark.svg`, `assets/park-welcome.svg`, and `assets/park-trail.svg` are the
Moss mark and Park Press illustrations from the approved screen source. They
contain no external resource references or user data.

## Archivo

The SIL Open Font License is reproduced in `fonts/archivo/OFL.txt`.
