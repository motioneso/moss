# Meetings design history

The earlier seven-screen design is superseded. Its critique is preserved only as historical
context, including proposals that the owner subsequently removed. It is not a build specification.

Build against the [current spec](../../specs/2026-10-06-meetings-minimal-design.md).
[#3087](https://github.com/motioneso/moss/pull/3087) owns the four Meetings screen sources;
this design PR records the owner's later meter, linking and Settings corrections without copying
screen or stylesheet bundles. Ordinary approval references stay in the
[canonical shared folder on main](https://github.com/motioneso/moss/tree/main/docs/superpowers/specs/approval-card).
No extra setup screen or recording approval is authorized by this history.

The obsolete pointer page, stylesheet copies and unused font files have been removed.
