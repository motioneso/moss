**Signature/shape:**

```ts
export const uatLevel = { level: "bare", without: [] } as const;

test("throwaway signup drives a real briefing generation to a rendered Today card, no old product name", async ({
  page
}) => {
  // 1. Sign up a throwaway account through the real auth UI (bare level -> needsBootstrap true,
  //    mode already "sign-up", no segmented-control collision).
  // 2. Land on Today page (index route redirects there); confirm the empty-state placeholder
  //    ("Your morning briefing is not ready yet.") is visible pre-generation.
  // 3. page.evaluate: POST /api/briefings/definitions
  //    { title: "UAT morning briefing", briefingType: "morning", enabled: true,
  //      selectedToolNames: ["vault"] } -> capture definition.id. Assert 201.
  // 4. page.evaluate: POST /api/briefings/definitions/{id}/run {} -> capture runId. Assert 202.
  // 5. Poll GET /api/briefings/definitions/{id}/runs (page.evaluate + a bounded retry loop, e.g.
  //    30 attempts / 2s apart = 60s ceiling) until runs.some(r => r.id === runId); assert the
  //    matched run's status === "succeeded" and summaryText is non-empty.
  // 6. page.reload() (fresh query fetch, no client-cache staleness).
  // 7. Assert the briefing card region is visible: kicker text "Morning briefing", title text
  //    "Your day, in focus", and the summary prose is rendered (not the "not ready yet" placeholder).
  // 8. Assert zero /Jarvis/i occurrences in the rendered card region's textContent.
  // 9. Screenshot the card region -> attach via test annotation / testInfo.attach for the PR proof.
```

enqueues, fallback path stops guaranteeing `succeeded`, or the old-name renames in briefing content
get reverted), this spec's poll times out or the `/Jarvis/i` assertion fires — both are real,
observable failures, not fixture artifacts.

**Cleanup:** none needed beyond the UAT harness's own `down -v` teardown (seam #1) — the whole run
