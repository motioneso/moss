  declarations into the package sheet flips them from last to before those five — a real risk.

  No other equal-or-lower-specificity collision exists. The escape hatch (spec line 99-100) is not
  needed.

  original selector order inside the new package block — override rules
  (`:hover`, `:focus`, `[disabled]`, `input:checked + …`, `:focus-visible`) all carry higher
  specificity than their base rule via a pseudo-class/attribute/compound selector, so they win
  regardless of position; base-rule vs base-rule order is unchanged because both move as one block.
