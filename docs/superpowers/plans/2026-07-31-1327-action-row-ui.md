### `briefing-action-rows.tsx` contract

```ts
export interface BriefingActionRowsSectionProps {
  readonly run: BriefingRunDto | null;
  readonly loading: boolean;
  readonly tasks: readonly TaskDto[];
  readonly locale: LocaleSettingsDto;
  readonly chatAvailable: boolean;
  readonly onOpenTask: (taskId: string) => void;
}
export function BriefingActionRowsSection(
  props: BriefingActionRowsSectionProps
): JSX.Element | null;

export interface DisplayedActionRow {
  readonly row: BriefingActionRowDto;
  readonly liveStatus: "suggested" | "accepted" | "dismissed";
}
export function joinActionRowsToTasks(
  rows: readonly BriefingActionRowDto[],
  tasks: readonly TaskDto[]
): readonly DisplayedActionRow[];
```

`joinActionRowsToTasks`: match by `taskId`; `status === "suggested"` → `"suggested"`;
`"todo"|"done"` → `"accepted"`; `"archived"` → `"dismissed"`; a row whose `taskId` has no matching
task is dropped. Displayed count = rows where `liveStatus === "suggested"`.

Category→control mapping (exact, exhaustive over the 3 v1 categories, no default branch):

- `needs_reply` → **Reply**, disabled with authored copy when `!chatAvailable`; calls
  `chatControls.openChatWith(\`Draft a reply to the cached email ${cacheMessageId} using email.draftReply.\`)`only when`primaryAction.kind === "reply"`.
- `needs_action` | `time_sensitive_info` → **View**, rendered only when `row.sourceHref` is
  non-null, `target="_blank" rel="noopener noreferrer"`; no control when null (never a fallback
  href).
- Accept/Dismiss always available on `liveStatus === "suggested"` rows; reuse
  `updateTask(row.taskId, {status: "todo"|"archived"})` + invalidate `queryKeys.tasks.list` and
  `queryKeys.briefings.runs(<current definition id>)`.

Authored states (verbatim strings, spec §8):

- loading → `Checking what needs you…`
- empty (run loaded, 0 suggested) → `You're caught up — nothing is waiting on you.`
- catch-up empty → omit the block entirely (no `BriefingCatchUpDto`, or `itemCount === 0`)
- stale → existing freshness-banner pattern keyed on the oldest displayed row's `computedAt`
- pre-briefing fallback (day mode only, spec §8): filter `tasks` where `status === "suggested"` and
  `sourceMetadata` matches `TaskSuggestionMetadataV1` shape (structural check against the existing
  schema shape, no new ajv dependency), synthesize `DisplayedActionRow[]` locally — the one place
  two data paths exist; document why in one comment line, not a mode flag threaded through the rest
  of the component.

Never interpolate `title`, `explanation`, `sourceLabel`, or any row text into a URL or the chat
instruction — only `cacheMessageId` (opaque) and `sourceHref` (pass-through).
