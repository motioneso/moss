## ⚠️ Standing rule — plan authorship and approval (Ben, 2026-08-29)

**Every implementation plan is WRITTEN by an Opus agent and APPROVED by a Fable agent.** A
Sonnet-authored plan is not valid, and coordinator approval does not substitute for the Fable gate.
Pipeline per lane is therefore three roles, not one:

1. **Opus planner** (`planners` tab) — authors the plan, no implementation.
2. **Fable approver** — approves or returns the plan. This is the approval gate.
3. **Sonnet builder** (`builders` tab) — executes the approved plan only; does not write its own.

The coordinator still holds merge authority and still reviews plans, but its opinion is advisory at
the plan gate now — Fable's approval is the gate.

**Companion rule (Ben, 2026-08-29):** a build task must fit ONE session. If it does not, it is
split into smaller issues rather than relayed forward. Planners size to this and report a proposed
split rather than padding a plan.
