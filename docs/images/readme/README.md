# README screenshots

Captured on September 5, 2026 from the real Moss web app in an isolated UAT instance using `ghcr.io/motioneso/moss:edge`.

Luke is fictional. His workspace contains nine tasks, five research notes, two goals, four contacts, eight calendar events, and 28 wellness check-ins. The research notes organize questions about type 1 diabetes; they do not report new clinical findings. No patient records or production account data were used.

News articles came from [ScienceDaily's Health feed](https://www.sciencedaily.com/rss/top/health.xml), preserving their original titles, dates, links, and images. Sports coverage and results came from ESPN. These are captured examples, not live scores or headlines.

The images are cropped Firefox viewport or section captures, encoded as JPEG. No UI text or data was replaced in the browser. Service workers were disabled in the capture browser so external images loaded directly. Screenshots demonstrate the interface, not offline/PWA behavior.
