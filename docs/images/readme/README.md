# README screenshots

Captured from the real Moss web app in an isolated UAT instance using `ghcr.io/motioneso/moss:edge`.

Luke's demo workspace spans work and personal life: 17 tasks across Work, Personal, and Home lists, five research notes, two goals, four contacts, eight calendar events, three medications, and 28 wellness check-ins. Personal records and medication history are sample data.

News combines BBC general-interest reporting with ScienceDaily research articles, retaining original titles, dates, links, and images. Sports follows Liverpool, the San Francisco Giants, the Buffalo Bills, the Anaheim Ducks, and San Diego FC, with coverage and results from ESPN. These are captured examples, not live scores or headlines.

The images are cropped Firefox viewport or section captures, encoded as JPEG. No UI text or data was replaced in the browser. Service workers were disabled in the capture browser so external images loaded directly.
