# Spec — issue #1987: include the rest of today's chats when archiving is turned on

## What's wrong today

Turning on chat archiving partway through a day only records messages sent
after that moment. Everything you chatted about earlier that same day is
left out of today's archived note. The daily note should read like a diary
of the whole day, not start mid-sentence.

## What changes

When the archive note for today is written, it includes every chat message
from the start of today up to now — both from before and after archiving
was turned on. This only applies to the day archiving is turned on; there
is no attempt to build or backfill notes for any earlier day. Turning
archiving on today never creates an archive note for yesterday or any
earlier day, because the note-writing job only ever runs for the current
day, triggered by today's own chat activity.

Private (incognito) chats are still never archived, before or after the
switch — that filter is unrelated to this change and already in place.

Concretely: remove the "only include messages at or after the moment
archiving was turned on" filter from the archive-day job. Today's cutoff
becomes the same as the account's local midnight, matching every other
day's note.

## Out of scope

- No changes to per-thread incognito filtering (already correct).
- No changes to which folder the note is written to, or its format.
- No UI changes; this is a backend fix.

## How it's verified

- Unit test: with archiving turned on partway through the day, the
  archive-day job includes messages sent both before and after that
  moment, for that same calendar day.
- Unit test: a message from a previous day is still excluded from today's
  note (the per-day boundary itself keeps working).
- Unit test: an incognito thread's messages are still excluded.
- Existing chat-archive tests continue to pass.
- Local checks (typecheck, lint, unit tests via the verify-gate skill) are
  green.
- Live-path proof: with archiving off, send a chat message. Turn archiving
  on. Send another message. Confirm today's archived note in the vault
  contains both messages.
